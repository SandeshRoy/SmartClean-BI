# SmartClean BI – Automated Data Cleaning & Reporting System

## Project Overview

SmartClean BI is a data cleaning and reporting automation project developed using Python and Power BI. The system automatically processes raw Amazon product datasets, cleans inconsistent data, handles missing values, removes duplicates, and generates visual reports through interactive dashboards.

## Objectives

* Automate data cleaning workflows using Python
* Handle missing values, duplicates, and inconsistent data
* Generate cleaned datasets for analysis
* Create interactive dashboards using Power BI
* Improve reporting efficiency through automation

## Technologies Used

* Python
* Pandas
* NumPy
* Power BI
* CSV Datasets

## Dataset

Amazon Products Sales Dataset 2023

Features:

* 300,000+ product records
* Multiple product categories
* Product ratings and reviews
* Price and discount information

## Project Workflow

Raw CSV Files
→ Python Cleaning Script
→ Cleaned Dataset
→ Power BI Dashboard
→ Automated Reporting

## Data Cleaning Operations

The Python automation script performs:

* Merging multiple CSV files
* Removing duplicate records
* Handling missing values
* Cleaning product ratings
* Cleaning number of ratings
* Cleaning price fields
* Standardizing text data
* Generating cleaned output datasets

## Power BI Dashboard Features

### KPI Cards

* Total Products
* Total Categories
* Average Rating
* Total Ratings

### Visual Reports

* Products by Category
* Average Rating by Category
* Average Price by Category
* Category Distribution Analysis
